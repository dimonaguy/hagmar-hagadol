### Enable GitHub Pages (one click)
1. Open https://github.com/dimonaguy/hagmar-hagadol/settings/pages
2. Under **Build and deployment → Source**, choose **GitHub Actions**
3. Re-run the workflow **Deploy GitHub Pages** (Actions tab → workflow_dispatch or push)
